## Prompt Logic Explanation

This prompt system is designed to generate
UGC-style ad content used in real paid campaigns.

### Why this works
- Starts with a strong hook to stop scrolling
- Highlights a relatable customer problem
- Uses first-person experience to build trust
- Shows a clear result or transformation
- Ends with a soft CTA for better conversions

### Reusability
This structure can be reused for:
- Local businesses
- D2C brands
- SaaS tools
- Creator brands
